# Code Review 스킬

코드를 보여주면 빠르게 3가지 관점으로 리뷰한다. 장황하게 쓰지 않고 핵심만.

---

## 리뷰 관점 3가지

### 1. 🐛 버그 / 잠재적 문제
- null/undefined 처리 누락
- 비동기 처리 실수 (await 빠짐 등)
- 조건문 엣지케이스

### 2. ⚡ 성능
- 불필요한 API 재호출
- v-for에 key 누락
- N+1 쿼리 (Spring Boot)
- 디바운스 필요한 이벤트

### 3. 🧹 코드 품질
- 변수명/함수명 명확한지
- 중복 코드
- 컴포넌트 분리 필요한 부분

---

## 출력 형식

```
🔍 코드 리뷰

🐛 버그 가능성
  - line 23: `userData`가 null일 때 `.name` 접근하면 에러남
    → `userData?.name ?? '알 수 없음'` 으로 수정

⚡ 성능
  - 카테고리 바꿀 때마다 API 재호출됨, 캐싱 고려해볼 것
  - v-for에 `:key` 없음 → `:key="post.id"` 추가

🧹 코드 품질
  - `handleClick1`, `handleClick2` → 이름 더 명확하게
  - 전체적으로 괜찮음 ✅

심각한 문제: 1개 / 권장 수정: 2개
```

---

## 규칙

- 칭찬보다 **문제점 먼저**
- 수정 방법을 **코드로** 같이 제시
- 심각도 구분: 🚨 반드시 고쳐야 함 / ⚠️ 권장 / 💡 선택
- Vue.js는 Options API 아닌 **Composition API** 기준으로 리뷰
- Spring Boot는 **JPA + REST 컨벤션** 기준
- 5줄 이하 짧은 코드면 바로 수정본도 같이 제시
