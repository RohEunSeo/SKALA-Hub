# Todo Tracker 스킬

개발 세션의 작업 목록을 만들고, 진행상황을 실시간으로 추적한다.

---

## 사용 시나리오

### A. 세션 시작 시 — 할 일 목록 생성

사용자가 "오늘 피드백 6개 반영해야 해" 같은 말을 하면:

```
📋 오늘 작업 목록 (6개)

  [ ] 1. 스켈레톤 UI 적용 (홈/순위보드/마이페이지)       ← 1번 피드백
  [ ] 2. 카테고리 변경 시 스크롤 초기화                  ← 4번 피드백
  [ ] 3. 정렬 기능 추가 (최신/인기/오래된순)             ← 2번 피드백
  [ ] 4. 순위보드 기간 필터 (오늘/이번주)                ← 6번 피드백
  [ ] 5. 홈화면 검색 기능                               ← 5번 피드백
  [ ] 6. 4층/5층 구분 필터                              ← 3번 피드백

난이도 쉬운 것부터 순서 잡았어요. 이 순서대로 할까요?
```

### B. 작업 중 — 진행상황 업데이트

사용자가 "4번 완료" 또는 "스크롤 다 고쳤어" 하면:

```
📋 진행상황 (2/6 완료)

  [✅] 1. 스켈레톤 UI 적용
  [✅] 2. 카테고리 변경 시 스크롤 초기화
  [ ] 3. 정렬 기능 추가
  [ ] 4. 순위보드 기간 필터
  [ ] 5. 홈화면 검색 기능
  [ ] 6. 4층/5층 구분 필터

다음: 정렬 기능 추가할까요?
```

### C. 세션 종료 시 — 완료 요약

"오늘 여기까지" 또는 커밋 후:

```
🎉 오늘 세션 완료 요약

  완료 (4/6):
  ✅ 스켈레톤 UI 적용
  ✅ 카테고리 변경 시 스크롤 초기화
  ✅ 정렬 기능 추가
  ✅ 순위보드 기간 필터

  다음 세션으로 이월 (2개):
  ⏳ 홈화면 검색 기능
  ⏳ 4층/5층 구분 필터
```

---

## 규칙

- 목록은 **난이도 낮은 것 → 높은 것** 순으로 자동 정렬 제안
- 완료 표시는 사용자가 명시적으로 말했을 때만 체크
- 다음 작업은 항상 한 개만 제안 (여러 개 나열 금지)
- 세션 중 "/todo" 치면 현재 진행상황 즉시 출력
