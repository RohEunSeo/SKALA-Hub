# Session Log 스킬

`/log` 또는 "오늘 작업 정리해줘" 하면 현재 대화창 전체를 분석해서 작업 일지를 만든다.

---

## 분석 항목

대화 전체를 읽고 아래 5가지를 추출한다:

### 1. 작업한 기능/수정 사항
- 새로 추가된 기능
- 수정된 버그
- 변경된 파일 목록

### 2. 트러블슈팅
- 발생한 문제
- 원인 파악 과정
- 해결 방법

### 3. 결정 사항
- 기술적 의사결정 (왜 이 방식을 선택했는지)
- 보류하거나 다음으로 미룬 결정

### 4. 미완료 / 다음 세션으로 이월
- 시작했지만 못 끝낸 것
- 발견됐지만 아직 안 고친 이슈

### 5. 커밋 히스토리 (있으면)
- 이번 세션에서 커밋한 내역

## 규칙

- 대화에서 **명시적으로 언급된 것만** 정리 (추측 금지)
- 작업 prefix는 `feat` / `fix` / `refactor` / `chore` / `docs` 로 통일
- 트러블슈팅은 **원인 → 해결** 흐름으로 간결하게
- 완료 못 한 것은 이월 목록에 그대로 올림 (빠짐없이)
- 커밋 내역은 이번 세션 대화에서 실제로 커밋한 것만 포함
- 일지는 마크다운 코드블록으로 복사하기 쉽게 출력
